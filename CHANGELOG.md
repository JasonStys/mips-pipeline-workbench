# Changelog

All notable changes follow semantic versioning and are recorded here.

## 1.1.0 native application candidate - 2026-11-11

- Actual editable/importable assembly and independent LRU inputs in the existing TypeScript explorer;
  fixed Rust JSON execution, exact reference/pipeline comparison, physical listings and diagnostics.
- Durable local SQLite experiment history with literal search, bounded pages, exact export,
  import-and-rerun and explicit deletion under record/byte budgets.
- Native workspace/Open/Help/Exit owner, pre-mutation aliases/program-root admission, exclusive lock,
  owned ephemeral capability/Origin API, patched Python floor and completion-based shutdown.
- Correct architectural Halt PC rather than speculative fetch cursor; independent regression across
  three programs and trace-retention caps. Existing demo changes only final PC 52 to 48.
- Original Rust/TS/container/browser gates retained; whole new Python package branch-aware 90% gate,
  actual extracted native GUI/persistence acceptance and all supported-language CodeQL lanes added.
- Current public delivery remains pending its separate accepted source/native release checks.

## [1.0.0] - 2026-09-18

### Added

- Two-pass MIPS-like assembler with labels, aliases, diagnostics, `.word`, `li`, and `move`.
- Independent sequential interpreter and five-stage pipeline implementation.
- Forwarding, load-use interlock, control-hazard flush, alignment checks, and bounded execution.
- Configurable set-associative LRU cache model.
- Versioned trace JSON and accessible TypeScript/HTML visualizer.
- Deterministic examples, 22 Rust tests, 4 TypeScript tests, repository policy, CI, CodeQL, Dependabot, and container build.
- Architecture, ISA, testing, security, operations, limitations, research, decision, code-index, and validation documentation.
