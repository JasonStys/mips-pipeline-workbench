          Help, privacy and supported model
          
    
            Start with a title and editable assembly, then Run assembly. Compare
            all 32 final registers, sparse memory, Halt PC and retirement count;
            inspect the physical source listing and the retained cycle explorer
            below. A model mismatch is saved as discrepancy evidence. Invalid or
            nonterminating inputs do not replace accepted evidence.
          
    
          
    
            Supported subset: arithmetic/logic, immediate operations, aligned
            loads/stores, branches, jumps, nop and halt as documented in the
            repository ISA profile. No interrupts, devices, speculative
            commercial CPU guarantees, self-modifying-code equivalence guarantee
            or live hardware. Maximum 4096 words, 10000 steps/cycles and 128 KiB
            UTF-8 source.
          
    
          
    
            History is local plaintext for this trusted OS user, with no
            account, telemetry, ads or external AI. Export important records and
            back up the stopped workspace outside application files. Up to 1000
            records and 100 MiB of evidence are retained; export and explicitly
            delete selected records when full. A browser refresh retains this
            tab's capability only for this server session.
          
    
          
    
            Use Open in the native owner window to reconnect. Exit retains
            ownership until active work finishes. Source and contact:
            Jason Stys on GitHub.

    Model boundaries
    
          
    What this trace proves
    
          
      
            
    • 
              EX/MEM and MEM/WB forwarding resolve arithmetic dependencies.
            
      • 
            
    • A load-use dependency inserts one decode/fetch interlock.
      • 
            
    • 
              Taken branches and jumps flush younger work before redirecting
              fetch.
            
      • 
            
    • 
              The Rust CLI can check results against an independent sequential
              interpreter. This viewer validates the file contract and bounds;
              imported evidence is not an execution proof.
            
      • 
          
    
          
    
            The workbench models an educational subset, not the timing or
            complete instruction set of a commercial processor. The exact
            boundary is documented with the source.
