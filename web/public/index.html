What this trace proves

  • EX/MEM and MEM/WB forwarding resolve arithmetic dependencies.
  • A load-use dependency inserts one decode/fetch interlock.
  • Taken branches and jumps flush younger work before redirecting fetch.
  • The Rust CLI can check results against an independent sequential interpreter. This viewer validates the file contract and bounds; imported evidence is not an execution proof.

The workbench models an educational subset, not the timing or complete instruction set of a commercial processor. The exact boundary is documented with the source.
